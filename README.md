# Ecommerce Clothing Brand

A modern, mobile-responsive ecommerce website for a clothing brand built with HTML, CSS, and vanilla JavaScript.

## Project Structure

```
├── public/images/     # Product & brand photos
├── src/
│   ├── pages/         # HTML pages
│   ├── css/           # Stylesheets
│   └── js/            # JavaScript modules
├── .kiro/specs/       # Requirements, design, and task specs
└── docs/              # GitHub CLI reference guide
```

## Pages

| Page | File |
|------|------|
| Homepage | `src/pages/index.html` |
| Shop | `src/pages/shop.html` |
| Product Detail | `src/pages/product.html` |
| Cart | `src/pages/cart.html` |
| Checkout | `src/pages/checkout.html` |
| About | `src/pages/about.html` |
| Contact | `src/pages/contact.html` |
| Login / Sign Up | `src/pages/auth.html` |

## Running Locally

No build step required. Open any HTML file directly in your browser, or use a simple local server:

```powershell
# With Python (if installed)
python -m http.server 8080

# Then open: http://localhost:8080/src/pages/index.html
```
